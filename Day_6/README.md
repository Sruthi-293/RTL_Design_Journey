🔧 Introduction to Synthesis Optimization

Synthesis optimization is the process of converting RTL code into an efficient hardware implementation while preserving its intended functionality.

The synthesis tool analyzes the RTL description and determines the logic elements required to implement the design. The way a circuit is coded can therefore have a direct effect on the hardware generated by synthesis.

During these experiments, I observed how incomplete assignments can result in latch inference, while complete combinational descriptions allow the synthesis tool to generate more predictable logic.

The overall flow followed was:

Verilog RTL → Simulation → Waveform Analysis → Synthesis → RTL Schematic → Hardware Understanding

⸻

📌 1. Incomplete IF Statement ⚠️

An incomplete IF statement occurs when an output is assigned only for a particular condition and no assignment is provided for the remaining conditions.

For combinational logic, this can cause the output to retain its previous value. During synthesis, the tool may therefore infer a latch to provide the required storage behavior.

📌 5. Incomplete Case Statement

Case statements are commonly used to describe selection logic such as multiplexers.

When a case statement does not cover all possible select conditions, the output may need to retain its previous value. This can result in latch inference during synthesis.

Verilog Code
module incomp_case (
    input i0,
    input i1,
    input i2,
    input [1:0] sel,
    output reg y
);

always @(*)
begin
    case(sel)
        2'b00 : y = i0;
        2'b01 : y = i1;
    endcase
end

endmodule

Only two select conditions are explicitly defined in this example. The remaining conditions do not contain an output assignment.

📌 6. Complete Case Statement ✅

A complete case statement provides an assignment for every possible input condition.

A default branch is commonly used to handle the remaining conditions and ensure that the output is always assigned.

Verilog Code
module comp_case (
    input i0,
    input i1,
    input i2,
    input [1:0] sel,
    output reg y
);

always @(*)
begin
    case(sel)
        2'b00 : y = i0;
        2'b01 : y = i1;
        default : y = i2;
    endcase
end

endmodule

📌 7. Partial Case Assignment

Partial assignment occurs when different outputs are assigned in different case branches, leaving some outputs without assignments under certain conditions.

Verilog Code
module partial_case_assign (
    input i0,
    input i1,
    input i2,
    input [1:0] sel,
    output reg y,
    output reg x
);

always @(*)
begin
    case(sel)
        2'b00 : begin
            y = i0;
            x = i2;
        end

        2'b01 : y = i1;

        default : begin
            x = i1;
        end
    endcase
end

endmodule

The example shows that y and x are not assigned in every branch.

📌 8. Bad Case Assignment

This experiment was used to study a case-based input selection circuit.

The design has four inputs and a 2-bit select signal. Each possible select combination is associated with one input.

Verilog Code
module bad_case (
    input i0,
    input i1,
    input i2,
    input i3,
    input [1:0] sel,
    output reg y
);

always @(*)
begin
    case(sel)
        2'b00: y = i0;
        2'b01: y = i1;
        2'b10: y = i2;
        2'b11: y = i3;
    endcase
end

endmodule

📌 10. Demultiplexer (DEMUX) 🔀

📌 11. Ripple Carry Adder ➕

An 8-bit Ripple Carry Adder is a combinational arithmetic circuit used to perform binary addition.

It consists of multiple full-adder stages connected in sequence. The carry generated from one stage becomes the carry input for the next stage.

Because the carry propagates through the stages, the circuit is called a Ripple Carry Adder.
