# RTL_Design_Journey
🔧 RTL Design & Synthesis Workshop

Welcome to my RTL Design and Synthesis Workshop repository! 🚀

This repository documents my hands-on learning journey in Verilog RTL Design, Simulation, Waveform Analysis, Logic Synthesis and RTL Optimization using open-source EDA tools.

The main goal of this workshop is to understand the complete journey of an RTL design:

RTL Code → Simulation → Waveform Analysis → Synthesis → Optimization

⸻
